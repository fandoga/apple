#  iPhone 15 Pro — Interactive Experience  
Вдохновлённый оригинальной страницей Apple, этот проект — полностью интерактивный, анимированный лендинг **iPhone 15 Pro**, созданный с упором на премиальную эстетику, динамику и глубину.

Каждый блок, анимация и 3D-элемент выполнены с целью создать ощущение фирменной подачи Apple: чисто, плавно, технологично.

Проект доступен по ссылке - [apple-tau-woad.vercel.app](https://apple-tau-woad.vercel.app/)

---

## ✨ Особенности

- **Тонкие, кинематографичные анимации**  
  Плавные переходы, параллакс, скролл-сцены — всё выполнено при помощи GSAP.

- **Фотореалистичный 3D-iPhone**  
  Использование Three.js + @react-three/fiber для высокодетализированной модели и интерактивного рендера.

- **Тонкая визуальная композиция**  
  Пространство, минимализм, фокус на важном — как на pages.apple.com.

- **Оптимизация под реальные устройства**  
  TailwindCSS + оптимизации Next.js дают впечатление нативного уровня.

## 🚀 Установка

### 1. Клонировать репозиторий  
```bash
git clone https://github.com/fandoga/apple.git
cd apple
npm install
npm run dev
```
Откройте: http://localhost:3000
